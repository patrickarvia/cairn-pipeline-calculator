# Cairn Deal Calculator

Cairn Deal Calculator is a lightweight enterprise sales tool for evaluating a single opportunity using actual deal evidence rather than CRM stage or intuition alone.

[Open the calculator](https://patrickarvia.github.io/cairn-pipeline-calculator/) · [Product overview](https://patrickarvia.com/deal-calculator/) · [Cairn GTM](https://cairngtm.com/) · [Built by Patrick Arvia](https://patrickarvia.com/)

The calculator evaluates an opportunity across six common enterprise deal signals:

- Executive sponsorship
- Multithreading
- Budget ownership
- Procurement progress
- Security / legal progress
- Mutually agreed next steps

## Why this exists

A deal can look healthy in the CRM while still lacking the evidence required to close.

The Cairn Deal Calculator makes those signals more explicit by evaluating the strength of the evidence behind an individual opportunity.

It is directional, not a forecasting model.

## Run locally

No installation is required.

1. Download or clone the repository.
2. Open `index.html` in any modern browser.
3. Adjust the six evidence signals and review the score.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save.

GitHub will provide a public URL after deployment.
